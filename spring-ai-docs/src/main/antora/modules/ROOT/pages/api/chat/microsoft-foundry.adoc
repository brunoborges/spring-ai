= Microsoft Foundry

Spring AI supports https://learn.microsoft.com/en-us/azure/ai-foundry/what-is-foundry[Microsoft Foundry] hosted chat models through the xref:api/chat/openai-chat.adoc[OpenAI Chat] model.
Starting with Spring AI `2.0.0-M5`, the OpenAI model uses the official `openai-java` SDK under the hood and can connect to OpenAI-compatible Foundry endpoints.

https://ai.azure.com/[Microsoft Foundry] is a top-level platform for enterprise AI operations, model builders, and application development.
For Spring AI users, Foundry can be configured as a first-class chat provider by using the OpenAI starter with a Foundry endpoint, credential, and deployment name.

== Prerequisites

Before you begin, you'll need:

1. An Azure account with an active subscription.
2. A https://learn.microsoft.com/en-us/azure/ai-foundry/how-to/create-projects[Microsoft Foundry project].
3. A deployed chat model in your Foundry project.
4. The OpenAI-compatible endpoint URL and either an API key or Microsoft Entra ID access.

== Auto-configuration

Spring AI provides Spring Boot auto-configuration for Microsoft Foundry through the OpenAI Chat starter.
Add the following dependency to your project:

[tabs]
======
Maven::
+
[source,xml]
----
<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-starter-model-openai</artifactId>
</dependency>
----

Gradle::
+
[source,groovy]
----
dependencies {
    implementation 'org.springframework.ai:spring-ai-starter-model-openai'
}
----
======

TIP: Refer to the xref:getting-started.adoc#dependency-management[Dependency Management] section to add the Spring AI BOM to your build file.

== Authentication

Microsoft Foundry supports API key authentication and passwordless authentication with Microsoft Entra ID.

=== API Key Authentication

Configure Spring AI with your Foundry endpoint, API key, and deployment name:

[source,properties]
----
spring.ai.openai.base-url=https://<your-resource-name>.openai.azure.com/openai/v1
spring.ai.openai.microsoft-foundry=true
spring.ai.openai.api-key=<your-api-key>
spring.ai.openai.chat.model=<your-deployment-name>
----

TIP: For enhanced security when handling sensitive information like API keys, use Spring Expression Language (SpEL) in your properties:

[source,properties]
----
spring.ai.openai.api-key=${MICROSOFT_FOUNDRY_API_KEY}
----

IMPORTANT: The `base-url` must point to the OpenAI-compatible endpoint provided by the Foundry portal or dashboard for your deployment.
When the endpoint includes an OpenAI-compatible path such as `/openai/v1`, set `spring.ai.openai.microsoft-foundry=true` explicitly.

TIP: For Foundry, `spring.ai.openai.chat.model` is used as the deployment name by default.
If your model name and deployment name differ, set `spring.ai.openai.microsoft-deployment-name=<your-deployment-name>` explicitly.

=== Passwordless Authentication

Microsoft Foundry supports passwordless authentication using Microsoft Entra ID.
This is recommended when running on Azure or in environments where Azure credentials are already available.

To enable passwordless authentication, add the Azure Identity dependency:

[source,xml]
----
<dependency>
    <groupId>com.azure</groupId>
    <artifactId>azure-identity</artifactId>
</dependency>
----

Then configure without an API key:

[source,properties]
----
spring.ai.openai.base-url=https://<your-resource-name>.openai.azure.com/openai/v1
spring.ai.openai.microsoft-foundry=true
spring.ai.openai.chat.model=<your-deployment-name>
----

Spring AI will use Azure credentials from the environment, such as Azure CLI credentials, managed identity, or environment-based credentials.

== Configuration Properties

The `spring.ai.openai` and `spring.ai.openai.chat` properties configure Microsoft Foundry access through the OpenAI Chat model.

[cols="3,5,1", stripes=even]
|====
| Property | Description | Default

| `spring.ai.openai.base-url` | The Foundry OpenAI-compatible endpoint. | `https://api.openai.com`
| `spring.ai.openai.microsoft-foundry` | Enables Microsoft Foundry provider mode explicitly. | `false`
| `spring.ai.openai.api-key` | The Foundry API key. Not required when using passwordless authentication. | -
| `spring.ai.openai.microsoft-deployment-name` | The deployment name defined in Microsoft Foundry. If not specified, the chat model value is used. | -
| `spring.ai.openai.microsoft-foundry-service-version` | Optional Microsoft Foundry API service version. | -
| `spring.ai.openai.chat.model` | The chat model or Foundry deployment name to use. | `gpt-5-mini`
| `spring.ai.openai.chat.temperature` | Sampling temperature for supported models. | `0.8`
| `spring.ai.openai.chat.max-tokens` | Maximum tokens for non-reasoning models. | -
| `spring.ai.openai.chat.max-completion-tokens` | Maximum completion tokens for reasoning models. | -
|====

For the full OpenAI Chat configuration surface, see xref:api/chat/openai-chat.adoc[OpenAI Chat].

== Getting Started Example

Create a new Spring Boot project and add `spring-ai-starter-model-openai`.
Then configure your Foundry deployment:

[source,properties]
----
spring.ai.openai.base-url=https://<your-resource-name>.openai.azure.com/openai/v1
spring.ai.openai.microsoft-foundry=true
spring.ai.openai.api-key=${MICROSOFT_FOUNDRY_API_KEY}
spring.ai.openai.chat.model=gpt-5-chat
----

You can then inject the portable Spring AI `ChatModel`:

[source,java]
----
@RestController
class ChatController {

    private final ChatModel chatModel;

    ChatController(ChatModel chatModel) {
        this.chatModel = chatModel;
    }

    @GetMapping("/ai/simple")
    Map<String, String> completion(@RequestParam(defaultValue = "Tell me a joke") String message) {
        return Map.of("completion", this.chatModel.call(message));
    }
}
----

== Migration Notes

The `spring-ai-azure-openai` and `spring-ai-openai-sdk` modules were removed in Spring AI `2.0.0-M5`.
Use `spring-ai-starter-model-openai` and the `spring.ai.openai.*` configuration properties for Microsoft Foundry.
